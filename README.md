# javascript-lotto-precourse

### 실행 흐름

1. App.run() 실행
2. 구입 금액 입력 → Parser.parseMoney() → Validator 검증
3. LottoMachine.issueLottoTicket()로 로또 발행
4. 당첨 번호 입력 → Parser.parseWinningNumbers() → Validator 검증
5. 보너스 번호 입력 → Parser.parseNumber() → Validator 검증
6. LottoMachine.checkLottoTickets()로 당첨 확인
7. 결과 집계 및 수익률 계산
8. View를 통한 결과 출력


### 프로젝트 아키텍처

```
src/
├── App.js                    # 메인 컨트롤러
├── View.js                   # 뷰 레이어 (입출력)
├── models/                   # 도메인 모델
│   ├── Lotto.js             # 로또 티켓 도메인 모델
│   └── LottoMachine.js      # 로또 발행 및 당첨 검증 로직
├── utils/                    # 유틸리티
│   ├── Parser.js            # 입력값 파싱
│   ├── Validator.js         # 유효성 검증
│   └── Retry.js             # 에러 처리 및 재시도 로직
└── constants/                # 상수 정의
    ├── gameConstant.js      # 게임 규칙 상수
    ├── message.js           # 출력 메시지
    └── error.js             # 에러 메시지
```

### 계층

#### 1. Controller Layer (App.js)
- 애플리케이션의 전체 흐름 제어
- 사용자 입력 처리 및 비즈니스 로직 호출

#### 2. View Layer (View.js)
- 사용자 입출력 처리

#### 3. Model Layer
**Lotto.js** - 로또 티켓 도메인 모델
- 로또 번호 유효성 검증 (길이, 중복)
- 당첨 번호와의 매칭 로직

**LottoMachine.js** - 로또 발행 및 검증 서비스
- 로또 티켓 발행 (랜덤 번호 생성)
- 당첨 결과 계산 및 순위 집계

#### 4. Utils Layer
**Retry.js** - 에러 처리 및 재시도
- 에러 발생 시 자동으로 재시도
- 에러 메시지를 사용자에게 출력
- 재귀 호출을 통한 재시도 구현

**Parser.js** - 입력값 파싱
- 문자열을 숫자로 변환
- 쉼표로 구분된 문자열을 배열로 파싱

**Validator.js** - 유효성 검증


## 기능목록

### 사용자 입력
- [x] 사용자에게 값을 입력받는다.

### 입력값 파싱
- [x] 로또 구입 금액을 파싱한다.
- [x] 숫자를 파싱한다.
- [x] 당첨 번호를 `,`을 기준으로 파싱한다.
- [x] 보너스 번호를 파싱한다.

### 게임진행
- [x] `(구입 금액 / 1000)`개 만큼 로또를 발행한다.
- [x] 발행한 로또에서 몇개가 당첨되었는지 확인한다.
- [x] 보너스 번호 당첨 여부를 확인한다.


### 사용자 출력
- [x] 발행한 로또 수량 및 번호를 출력한다. 로또는 오름차순으로 정렬하여 보여준다.
- [x] 당첨 내역을 출력한다.
- [x] 수익률을 출력한다.

### 유틸리티
- [x] 수익률을 소수점 둘째 자리에서 반올림한다.

### 예외 상황
- [x] 예외 사항 시 `[ERROR]`로 시작하는 에러 문구를 출력한다.
- [x] 입력 상황에서 예외 발생시 해당 지점부터 다시 입력받는다.
#### 구입 금액
- [x] 구입 금액이 숫자가 아닐시 예외를 발생시킨다.
- [x] 구입 금액이 양수가 아닐시 예외를 발생시킨다.
- [x] 구입 금액이 1000원으로 나누어 떨어지지 않으면 예외를 발생시킨다.
#### 당첨 번호
- [x] 당첨 번호가 숫자가 아닐시 예외를 발생시킨다.
- [x] 당첨 번호가 정수가 아닐시 예외를 발생시킨다.
- [x] 당첨 번호가 1~45 사이 숫자가 아닐 시 예외를 발생시킨다.
#### 로또 번호
- [x] 로또 번호가 6개가 아닐 시 예외를 발생시킨다.
- [x] 로또 번호에 중복된 숫자가 있을 시 예외를 발생시킨다.
#### 보너스 번호
- [x] 보너스 번호가 숫자가 아닐시 예외를 발생시킨다.
- [x] 보너스 번호가 정수가 아닐시 예외를 발생시킨다.
- [x] 보너스 번호가 1~45 숫자가 아닐 시 예외를 발생시킨다.
