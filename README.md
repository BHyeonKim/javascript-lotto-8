# javascript-lotto-precourse

## 기능목록

### 사용자 입력
- [x] 사용자에게 값을 입력받는다.

### 입력값 파싱
- [ ] 로또 구입 금액을 파싱한다.
- [ ] 담청 번호를 `,`을 기준으로 파싱한다.
- [ ] 보너스 번호를 파싱한다.

### 게임진행
- [ ] `(구입 금액 / 1000)`개 만큼 로또를 발행한다.
- [x] 발행한 로또에서 몇개가 당첨되었는지 확인한다.
- [x] 보너스 번호 당첨 여부를 확인한다.


### 사용자 출력
- [ ] 발행한 로또 수량 및 번호를 출력한다. 로또는 오름차순으로 정렬하여 보여준다.
- [ ] 담첨 내역을 출력한다.
- [ ] 수익률을 출력한다.

### 유틸리티
- [ ] 수익률을 소수점 둘째 자리에서 반올림한다.

### 예외 상황
- [ ] 예외 사항 시 `[ERROR]`로 시작하는 에러 문구를 출력한다.
- [ ] 입력 상황에서 예외 발생시 해당 지점부터 다시 입력받는다.
#### 구입 금액
- [ ] 구입 금액이 숫자가 아닐시 예외를 발생시킨다.
- [ ] 구입 금액이 1000원으로 나누어 떨어지지 않으면 예외를 발생시킨다.
#### 당첨 번호
- [ ] 당첨 번호가 숫자가 아닐시 예외를 발생시킨다.
- [ ] 당첨 번호가 정수가 아닐시 예외를 발생시킨다.
- [ ] 당첨 번호가 1~45 사이 숫자가 아닐 시 예외를 발생시킨다.
#### 로또 번호
- [x] 로또 번호가 6개가 아닐 시 예외를 발생시킨다.
- [x] 로또 번호에 중복된 숫자가 있을 시 예외를 발생시킨다.
#### 보너스 번호
- [ ] 보너스 번호가 숫자가 아닐시 예외를 발생시킨다.
- [ ] 보너스 번호가 정수가 아닐시 예외를 발생시킨다.
- [ ] 보너스 번호가 1~45 숫자가 아닐 시 예외를 발생시킨다.



## 프로세스
- [ ] 1. 로또 구입 금액을 입력 받는다. (구입 금액은 1000원 단위로 입력받는다.).  
        1-1. 로또 구입 금액을 파싱한다.   
        Exception. 1000원으로 나누어 떨어지지 않는 경우 예외 처리한다.   
        Exception. 예외가 발생했을 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력후 해당지점 부터 다시 입력받는다.   
- [ ] 2. `(구입 금액 / 1000)`개 만큼 로또를 발행한다.
- [ ] 3. 당첨 번호를 입력받는다.   
        3-1. 당첨 번호를 `,`를 기준으로 파싱한다.   
        Exception. 파싱한 당첨 번호가 숫자가 아니면 예외 처리한다.   
        Exception. 파싱한 당첨 번호에 중복이 있으면 예외 처리한다.   
        Exception. 파싱한 당첨 번호가 1~45 사이의 숫자가 아니면 예외처리한다.   
        Exception. 예외가 발생했을 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력후 해당지점 부터 다시 입력받는다.   
- [ ] 4. 보너스 번호를 입력받는다.   
        4-1. 보너스 번호를 파싱한다.   
        Exception. 파싱한 당첨 번호가 숫자가 아니면 예외처리한다.   
        Exception. 파싱한 당첨 번호가 1~45 사이의 숫자가 아니면 예외처리한다.   
        Exception. 예외가 발생했을 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력후 해당지점 부터 다시 입력받는다.    
- [ ] 5. 당첨 내역을 구한다.   
- [ ] 6. 당첨 내역을 출력한다.   
        6-1. 수익률은 소숫점 둘째 자리에서 반올림 한다.
