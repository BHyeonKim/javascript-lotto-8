# javascript-lotto-precourse

## 프로세스
- [ ] 1. 로또 구입 금액을 입력 받는다. (구입 금액은 1000원 단위로 입력받는다.).  
        1-1. 로또 구입 금액을 파싱한다.   
        Exception. 1000원으로 나누어 떨어지지 않는 경우 예외 처리한다.   
        Exception. 예외가 발생했을 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력후 해당지점 부터 다시 입력받는다.   
- [ ] 2. `(구입 금액 / 1000)`개 만큼 로또를 발행한다.
- [ ] 3. 당첨 번호를 입력받는다.   
        3-1. 당첨 번호를 `,`를 기준으로 파싱한다.   
        Exception. 파싱한 당첨 번호가 숫자가 아니면 예외 처리한다.   
        Exception. 파싱한 당첨 번호에 중복이 있으면 예외 처리한다.   
        Exception. 파싱한 당첨 번호가 1~45 사이의 숫자가 아니면 예외처리한다.   
        Exception. 예외가 발생했을 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력후 해당지점 부터 다시 입력받는다.   
- [ ] 4. 보너스 번호를 입력받는다.   
        4-1. 보너스 번호를 파싱한다.   
        Exception. 파싱한 당첨 번호가 숫자가 아니면 예외처리한다.   
        Exception. 파싱한 당첨 번호가 1~45 사이의 숫자가 아니면 예외처리한다.   
        Exception. 예외가 발생했을 경우 `[ERROR]`로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력후 해당지점 부터 다시 입력받는다.    
- [ ] 5. 당첨 내역을 구한다.   
- [ ] 6. 당첨 내역을 출력한다.   
        6-1. 수익률은 소숫점 둘째 자리에서 반올림 한다.
